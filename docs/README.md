# Screenshots

The images shown in the main [README](../README.md) are **UI mockups** (`*.svg`) rendered
from the actual on‑device layout and colours — not real device photos.

To use real photos instead, replace these files (keep the same names, or update the paths
in the README):

| File | Screen |
|------|--------|
| `menu.svg` | The home menu |
| `metronome.svg` | Metronome running |
| `tuner.svg` | Tuner showing a note + cents meter |
| `chords.svg` | Chord Progression with a fingering diagram |
| `record.svg` | Record & Check result screen |

Tips for real photos:
- A straight‑on phone photo of the 240×135 screen is fine; crop to just the display.
- If you save as `.jpg`/`.png`, update the extensions in the README's Screenshots section.
