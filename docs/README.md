# Screenshots

Put device photos here so they appear in the main [README](../README.md).

Expected filenames (referenced by the README's Screenshots section):

| File | Screen to capture |
|------|-------------------|
| `menu.jpg` | The home menu |
| `metronome.jpg` | Metronome running (beat dots lit) |
| `tuner.jpg` | Tuner showing a note + cents meter |
| `chords.jpg` | Chord Progression with a fingering diagram |
| `record.jpg` | Record & Check result screen |

Tips:
- A straight-on phone photo of the 240×135 screen is fine.
- Crop to just the display for a clean look.
- `.jpg` or `.png` both work — update the extensions in the README if you use `.png`.
